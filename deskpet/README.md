# DeskPet firmware

ESP32-S3 desk companion (ES3C28P board). Build with arduino-cli from this folder.

## Layout

```
deskpet/
├── deskpet.ino          Entry point (setup/loop). The folder and this file must share a name.
├── *.cpp, *.h           Firmware modules. Kept flat on purpose: arduino-cli compiles only
│                        the sketch root, so modules in subfolders would not be built.
├── ui_assets.h          Generated by tools/generate_ui_assets.py
├── partitions.csv       Partition table (PartitionScheme=custom reads it from the sketch root)
├── sketch.yaml          Board profile, core and library versions
├── arduino-cli.yaml     arduino-cli config (user dir = .arduino/)
├── assets/              Companion asset pack
│   ├── page-mascot/     Source sprite sheets and LICENSE
│   ├── pets.bin         Generated pack, flashed to the "assets" partition at 0x610000
│   ├── manifest.json    Generated summary of pets.bin
│   └── previews/        Preview images of the sprites
├── tools/               Host-side build, QA and serial probe scripts
├── qa/
│   ├── logs/            Captured serial and tool output (*.log)
│   ├── snapshots/       Framebuffer PNGs written by tools/verify_pet_assets.py
│   └── fixtures/        Saved device settings and alarm states
├── build/, out/         arduino-cli build path and output dir (generated)
└── .arduino/            arduino-cli user dir: installed libraries and cores
```

## Commands

Compile (run from this folder; use a different folder for `--build-path` and `--output-dir`):

```bash
arduino-cli compile --config-file arduino-cli.yaml --profile es3c28p --build-path build --output-dir out .
```

Regenerate assets:

```bash
python tools/generate_ui_assets.py
python tools/build_pet_assets.py
```

Verify a connected board:

```bash
python tools/verify_pet_assets.py --port COM9
```
